## How this works

- Every document is a standalone HTML page under `guides/` (or future folders).
- GitHub Pages serves the `main` branch, so each file gets a shareable public URL:
  `https://dusengeyezu.github.io/docs/<path>.html`
- [`index.html`](index.html) is the hub landing page listing everything.

To add a document: drop the `.html` file in a folder, add it to `index.html` and this README, commit, push.
